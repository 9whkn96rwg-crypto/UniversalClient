Warum funktioniert Java hier noch nicht?

Eine Webseite kann Minecraft Java nicht einfach selbst starten. Dafür werden eine kompatible Laufzeitumgebung und eine gültige Minecraft-Lizenz benötigt. Diese Webseite stellt keinen Java-Launcher bereit.
