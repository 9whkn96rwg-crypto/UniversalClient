☕ Java Edition

Java-Bereich

Hier kannst du deine Java-Server verwalten und Informationen zu deinen Servern speichern.

Der Java-Spielstart ist auf dieser iPad-Webseite noch nicht integriert. Zum Spielen werden eine kompatible Java-Laufzeit und eine gültige Minecraft-Java-Lizenz benötigt.

🟩 Bedrock Edition

Minecraft Bedrock öffnen

Öffne Minecraft direkt aus UniversalClient auf deinem iPad.

Die Webseite kann Minecraft öffnen, aber nicht automatisch einen gespeicherten Server auswählen oder eine bestimmte Spielversion einstellen. Wähle deinen Server anschließend in Minecraft aus.

ℹ About UniversalClient

About the Project

UniversalClient ist ein unabhängiges Webprojekt, das Java- und Bedrock-Bereiche in einer gemeinsamen Oberfläche zusammenführt.

Das Projekt befindet sich in Entwicklung. Weitere Funktionen und Verbesserungen sind geplant.
